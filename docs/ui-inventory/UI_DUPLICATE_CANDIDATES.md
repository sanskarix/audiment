## 2. In-App Pattern Duplicates Across Portals

- **Filters & Search Bars**: `/dashboard/admin/audits`, `/dashboard/manager/audits`, `/dashboard/admin/users`, `/dashboard/admin/reports` each implement their own local filter and search controls with varying padding (`h-9`, `h-10`, `h-11`, `.filter-btn`).
- **Metric / KPI Cards**: Metric cards across `/dashboard/admin` and `/dashboard/manager` use different layout structures and subtitle spacing for stat numbers.
- **Status Badges**: Audit status badges are defined globally via `.badge-completed`, `.badge-in-progress`, etc. in `app.css`, while other screens use inline Tailwind badges (`bg-emerald-500/10 text-emerald-600`).
- **Action Modals**: Add Location (`/admin/locations`), Add User (`/admin/users`), Add Auditor (`/manager/auditors`), and New Audit (`/admin/audits`) each implement custom modal layout wrappers.
