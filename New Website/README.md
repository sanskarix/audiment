# Audiment Takeout

This standalone folder contains **all redesigned pages, components, and assets** for Audiment.
It has been completely separated from the Asellus website project.

## Included Pages (15 Redesigned Pages)
1. **Home**: `index.html` & `audiment.html` (served at `/` or `/audiment`)
2. **About**: `audiment/about/index.html` (`/audiment/about`)
3. **Blog Index**: `audiment/blog/index.html` (`/audiment/blog`)
4. **Blog Post (Sample/Dynamic)**: `audiment/blog/post/index.html` (`/audiment/blog/:slug`)
5. **Solutions**: `audiment/solutions/index.html` (`/audiment/solutions`)
6. **Restaurant Audit Software**: `solutions/restaurant-audit-software/index.html`
7. **Proof-Based Audits**: `platform/proof-based-audits/index.html`
8. **Use Cases**: `audiment/use-cases/index.html` (`/audiment/use-cases`)
9. **Multi-Location Audit Software**: `audiment/multi-location-audit-software/index.html`
10. **Compare Hub**: `audiment/compare/index.html` (`/audiment/compare`)
11. **Compare vs SafetyCulture**: `audiment/compare/audiment-vs-safetyculture/index.html`
12. **Operational Drift**: `audiment/operational-drift/index.html` (`/audiment/operational-drift`)
13. **Cookie Policy**: `audiment/cookie-policy/index.html` (`/audiment/cookie-policy`)

15. **Terms of Service**: `audiment/terms-of-service/index.html` (`/audiment/terms-of-service`)

## Offline Usage
You can run this project completely locally and offline:

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev

# 3. Or build production static files
npm run build

# 4. Preview built static files offline
npm run preview
```
