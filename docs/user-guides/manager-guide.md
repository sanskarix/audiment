# Manager Operational Handbook

The **Manager Dashboard** (`/dashboard/manager`) enables branch and regional managers to delegate audit assignments to field inspectors, resolve CAPA tasks, and track branch scores.

---

## 🛠️ Key Operational Workflows

### 1. Delegating Audits to Auditors
* Navigate to **Audits Queue**.
* View newly published audits assigned to your locations.
* Click **Assign Auditor**, select an active auditor from your team, and confirm delegation.

### 2. Resolving Corrective Actions (CAPA Queue)
* Navigate to **Corrective Actions**.
* Items display an active 48-hour SLA countdown.
* Click **Resolve Item**.
* Type a detailed resolution note describing the operational fix applied.
* Upload a required photo proving the issue is rectified.
* Click **Mark Resolved**.

### 3. Manager Calendar View
* View upcoming scheduled non-surprise audits and deadlines on an interactive monthly calendar.
